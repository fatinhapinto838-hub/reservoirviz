# Roadmap

These are proposed development milestones, not implemented features or promises of eligibility for any grant or subscription program.

## v0.1.0 — CSV workflow

- CSV reading settings and explicit column mapping.
- Numeric/time checks, time and pressure conversions.
- Pressure and rate charts, offline report, CSV + metadata exports.
- Synthetic examples, installation instructions, tests, contribution templates.

## Next — validate real usage

- Check at least one permitted real export against its source software and manually checked values.
- Record the software/module, units, reference conditions, mappings, and limitations.
- Ask early users to try the documented installation and report specific problems.
- Fix reproducible issues and publish honest change notes.

## Candidate v0.2.0 features

- Multi-case comparisons with documented alignment rules.
- Saved/importable mapping profiles and structured reference-condition metadata.
- Better import adapters based on real exported files.
- Bilingual UI if users request it.
- Static scientific figure export with reproducible fonts and dimensions.

## Later, after defining the calculations

- Injection/shut-in/production stage annotation.
- Cumulative rates with an explicit sampling and integration convention.
- Component accounting only when composition, units, conditions, and balance definitions are available.

## Evidence of maintenance

Use actual Issues, fixes, reviews, releases, and usage reports. Do not manufacture users, stars, downloads, test results, or affiliations. A functioning first release is the beginning of maintenance; it does not establish broad adoption on its own.
