# ReservoirViz 首版使用指南

这个版本用于读取单井或单案例的 CSV，检查数据、绘制压力与注采曲线，并导出结果。可直接在 Mac 上运行。

## 1. 安装 Python

推荐 Python 3.12。安装入口：[Python 官方下载](https://www.python.org/downloads/)。安装后在终端输入 `python3 --version`；Windows 可用 `py -3.12 --version`。

macOS 自带的 Python 3.9 不适用于这份依赖配置。安装新版后再启动项目。

## 2. 启动

解压项目，将整个 `reservoirviz` 文件夹放在固定位置。

- Mac：双击 `run_mac.command`。如果系统没有直接执行它，在终端进入项目目录后输入 `bash run_mac.command`。
- Windows：双击 `run_windows.bat`。

首次启动会在项目目录创建 `.venv` 并联网安装依赖，耗时取决于网络。完成后浏览器通常会打开 <http://localhost:8501>。后续启动会复用该环境。关闭页面不会停止服务；在启动它的终端按 Ctrl+C 可停止。

如果需要手动安装，在项目目录执行：

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address=127.0.0.1
```

Windows 命令提示符使用：

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.address=127.0.0.1
```

## 3. 先体验演示

默认显示 120 行合成数据和两张图。它是三个示意注、焖、采周期，未经过储层物理验证。不要把它作为真实 CMG 模拟结果使用。

在图上悬停可查看数值，拖动可放大，双击可恢复。图表工具栏提供浏览器端 PNG 保存功能；发布版的基础交付格式是交互 HTML。

## 4. 读取自己的 CSV

1. 左侧切换到“上传 CSV”，选择文件。
2. 文件包含说明行时，展开“CSV 读取设置”，填写需要跳过的开头行数。支持一行表头。
3. 检查列分隔符、小数分隔符和编码。
4. 给时间、压力、注入速率、产出速率选择对应列。时间必选，其余至少一项；可以选择“不使用”。
5. 确认源数据单位。程序只自动转换时间和压力；速率数值不会改变。
6. 在“数据与检查”核对几行输出，确认数值与原始结果一致。

一份文件中的时间必须唯一。多井结果可能在同一时间出现多个记录，应先按井拆成不同文件。程序不会自行删除、平均或合并重复值。

## 5. 保存结果

在“导出与说明”中下载：

- HTML：含交互图表、来源哈希和单位，可离线打开。
- CSV：整理后的数值数据，时间统一为 day、压力统一为 MPa。
- JSON：字段对应、原始单位、读取设置及数据提示。

CSV 中的 `injection_rate` 和 `production_rate` 没有固定质量或体积单位，必须与 JSON 一起保存。不同参考条件的体积速率不能直接比较或相减。

## 常见问题

| 提示 | 处理方式 |
|---|---|
| 只识别到一列 | 调整列分隔符，或检查表头前的说明行 |
| 表头存在重复列名 | 为各列设置唯一名称 |
| 列数与表头不一致 | 检查引号、缺失字段和分隔符 |
| 缺失、非数值或无穷值 | 按提示的数据行修正源文件；程序不自动删行 |
| 时间存在重复值 | 检查多井/多案例混排或重复输出 |
| 请确认单位 | 给对应字段选择源文件实际单位 |
| 8501 端口已使用 | 先关闭已有实例，或手动启动时增加 `--server.port=8502` |
| 安装依赖失败 | 检查 Python 版本与网络，将终端的完整错误保留供排查 |

## 使用范围

当前不读取 SR3、网格或日历日期；不计算累计注采、采收率及 CO₂ 埋存率。负速率保留原始符号并给出提示；流向、压力基准和标准体积参考条件需按源软件核对。自己的真实 CSV 尚需逐份核验，内置演示通过不代表所有导出格式均受支持。
