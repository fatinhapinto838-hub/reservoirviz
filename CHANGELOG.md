# Changelog

## 0.1.0 — 2026-10-23

- Added a Chinese Streamlit interface for single-well / single-case CSV analysis.
- Added source column mapping, CSV settings, validation, and explicit units.
- Added time and pressure conversion, preserving rate values and sign conventions.
- Added pressure/rate plots, offline HTML reports, normalized CSV and JSON metadata.
- Added synthetic examples, local launchers, documentation, tests, and GitHub CI configuration.

Initial scope: real user CMG exports and Windows execution still require validation. Native SR3, grid visualization, cumulative quantities, and storage accounting are not implemented.
